# 実行方法

### 1. 手動入力する場合
実行すると入力待ちになるので、入力例をキーボードで打ち込む。
```bash
ruby ディレクトリ名/ファイル名.rb
```

### 2. 入力をまとめて渡す場合
`echo`で入力例を流し込む。複数行の場合は改行で区切る。
```bash
# 1行
echo "入力値" | ruby ディレクトリ名/ファイル名.rb

# 複数行
echo "入力値
入力値" | ruby ディレクトリ名/ファイル名.rb
```
